## 2. Название

Одинаково для обоих языков, **не переводить**:

```
Tiny Sprout
```

Именно это написано в `<title>` игры и на обеих обложках. Расхождение названия
между полями черновика и промоматериалами — самая частая причина отказа
(п. 5.1.3).

Tiny Sprout is a calm little farming game. Tap the beds to plant and harvest, sell your produce from the barn and reinvest the coins into new crops, plots and greenhouses.

## 6. Лидерборд — завести вручную

Единственный шаг, который нельзя сделать из кода.

| Параметр | Значение |
| --- | --- |
| Техническое имя | `goldenSeeds` |
| Тип значения | Целое число |
| Сортировка | По убыванию |
| Название [ru] | `Золотые семена` |
| Название [en] | `Golden seeds` |

Техническое имя должно совпасть буква в букву — оно захардкожено в `game.js`
(константа `LB_NAME`). Иначе вкладка «Рейтинг» покажет ошибку загрузки.

## 7. Монетизация

| Тип рекламы | Используется |
| --- | --- |
| Rewarded video | **Да** — за удвоение дохода, ускорение роста и удвоение офлайн-награды |
| Полноэкранная (interstitial) | Нет |
| Внутриигровые покупки | Нет |

Достаточно включить монетизацию в настройках игры, отдельных сущностей
заводить не нужно.

## 8. Для анкеты возрастного рейтинга

Игра содержит:

- насилие, кровь, страшные сцены — **нет**
- азартные игры, симуляция ставок, лутбоксы за деньги — **нет**
- ненормативная лексика — **нет**
- реклама алкоголя, табака, лекарств — **нет**
- общение между игроками, чат, пользовательский контент — **нет**
- сбор персональных данных — **нет**: сохраняется только игровой прогресс
  через `player.setData`, с откатом в `localStorage`
- сторонние сети и аналитика — **нет**: единственный внешний ресурс — сам
  SDK Яндекс Игр, шрифты и графика лежат внутри архива

## 10. Проверка перед отправкой

Откройте тестовую ссылку черновика и убедитесь, что:

- прогресс сохраняется между сессиями;
- rewarded-ролик показывается по кнопкам «Доход x2» и «Дорастить всё»;
- вкладка «Рейтинг» наполняется, а гостю предлагается вход;
- интерфейс на нужном языке сразу, без переключения на глазах.

Вне домена Яндекса SDK не загружается и игра уходит в `localStorage` — это
ожидаемое поведение, а не баг.
