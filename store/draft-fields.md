| Ориентация | **Любая** |
| Игра переведена на | Русский, Английский |
| Возрастной рейтинг | 0+ |
| Категории | Казуальные + **Симуляторы** |
| Игра использует облачные сохранения | **Включить** |

**Облачные сохранения обязательно включить** — игра пишет прогресс через
`player.setData` (`game.js`, функция `persist`), с откатом в `localStorage`.
Если тумблер оставить выключенным, заявленное поведение не совпадёт с реальным.

**Ориентация «Любая»** подтверждена: вёрстка проверена на 320×568, 360×640,
640×360, 768×1024 и 1280×720 — нигде не обрезается, горизонтальной прокрутки нет.

Можно добавить `кликеры`, `симуляторы`, `животные`.

## Название (11/50) — одинаково на обеих вкладках, не переводить

```
Tiny Sprout
```

Ровно так же написано в `<title>` игры и на обеих обложках. Расхождение
названия между полями черновика и промоматериалами — самая частая причина
отказа (п. 5.1.3).

# Скриншоты

Загружаются на каждой языковой вкладке отдельно, а внутри вкладки —
переключателем «Десктопные / Мобильные».

| Переключатель | Ориентация скриншотов | Файлы из `store/screenshots/` |
| --- | --- | --- |
| Десктопные, вкладка Русский | Альбомная | `desktop-ru-1-farm` · `-2-beds` · `-3-animals` · `-4-shop` |
| Мобильные, вкладка Русский | Портретная | `mobile-ru-1-farm` · `-2-beds` · `-3-animals` · `-4-shop` |
| Десктопные, вкладка Английский | Альбомная | `desktop-en-1-farm` · `-2-beds` · `-3-animals` · `-4-shop` |
| Мобильные, вкладка Английский | Портретная | `mobile-en-1-farm` · `-2-beds` · `-3-animals` · `-4-shop` |

Порядок — по номеру в имени файла. Если форма примет только три, берите
`1-farm`, `2-beds`, `3-animals`: на них геймплей занимает весь кадр без
перекрытия панелями.

**Видео геймплея и рекламные видео** — необязательные поля, у нас их нет.
Можно оставить пустыми.

# Лидерборд — завести вручную

Единственный шаг, который нельзя сделать из кода.

| Параметр | Значение |
| --- | --- |
| Техническое имя | `goldenSeeds` |
| Тип значения | Целое число |
| Сортировка | По убыванию |
| Название [ru] | `Золотые семена` |
| Название [en] | `Golden seeds` |

Имя должно совпасть буква в букву — оно захардкожено в `game.js` (`LB_NAME`).
Иначе вкладка «Рейтинг» покажет ошибку загрузки.

# Для анкеты возрастного рейтинга

Проверено по коду. Игра содержит:

- насилие, кровь, страшные сцены — **нет**
- азартные игры, ставки, лутбоксы — **нет**
- ненормативная лексика — **нет**
- реклама алкоголя, табака, лекарств — **нет**
- чат, общение между игроками, пользовательский контент — **нет**
- сбор персональных данных — **нет**: сохраняется только игровой прогресс
- сторонние сети и аналитика — **нет**: единственный внешний ресурс —
  SDK Яндекс Игр, шрифты и графика лежат внутри архива

# Проверка перед отправкой

Откройте тестовую ссылку черновика и убедитесь, что:

- прогресс сохраняется между сессиями;
- rewarded-ролик показывается по кнопкам «Доход x2» и «Дорастить всё»;
- вкладка «Рейтинг» наполняется, а гостю предлагается вход;
- интерфейс сразу на нужном языке, без переключения на глазах.

Вне домена Яндекса SDK не загружается и игра уходит в `localStorage` — это
ожидаемое поведение, а не баг.
